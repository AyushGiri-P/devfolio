# My Portfolio

A responsive personal portfolio website built with semantic HTML and CSS.

## Description

This portfolio showcases my web development projects, introduces me,
and provides links to my contact and professional profiles.

## Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No build tools or dependencies are required.
